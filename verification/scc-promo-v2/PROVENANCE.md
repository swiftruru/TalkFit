# TalkFit SCC 宣傳圖 v2 來源

- 擷取裝置：iPhone 17 Pro Simulator，iOS 26.5
- App 版本：Git `f2f99cc` 之後的本機修正版
- 擷取與驗證：XcodeBuildMCP；所有主要畫面均透過 `serve-sim` 在 Codex in-app browser 目視確認
- 真實畫面：首頁、示範錄音、練習報告、前後比較、具 QA fixture 的本機錄音紀錄
- 品牌素材：
  - `TalkFit/Assets.xcassets/AppIcon.appiconset/AppIcon.png`
  - `TalkFit/Assets.xcassets/PaperBackground.imageset/paper-background.png`
- 確定性排版：`verification/scc-promo-v2/render_promos.swift`
- 輸出尺寸：1290 × 2796 px PNG

手機內的 UI 全部來自實際執行中的 TalkFit。外層標題、步驟標籤、紙張背景與裝置框為 SCC 展示排版；沒有使用生成式影像重畫產品畫面或改寫數據。
